s3dol.reads

Read strategies (ADR-0005 §6): what s[k] returns.

s[k] returns bytes — always, under the default strategy, because the N1 canonical form demands it. stream_reads is the documented runtime variation (the store’s values become chunk iterators); it does not change the class’s static value type — honest typing there would need a generic store, which v1 does not do.

Ranged reads and download-to-disk are per-object concerns and live on ObjectHandle (handle.read(offset=, length=), handle.download_to), not here — a store-level “ranged” strategy would need a per-key range, which a Mapping cannot express.

Strategies are frozen dataclasses, not closures, because every s3dol store must pickle (ADR-0008 §6) and a store carries its strategy.
